# QA Regression Analysis & Reporting Automation

**Domain:** QA & Release Management
**Tools:** Power Automate · SharePoint · HTML · Outlook

---

## Problem
- QA teams shared regression results via unstructured emails every cycle
- BAs and PMs manually compared results across ~90 modules
- Time-consuming, error-prone, and not scalable

## Solution
- Built an end-to-end automated workflow
- Parses raw QA emails → extracts module-wise metrics → compares with previous cycle → classifies status → sends formatted HTML summary to stakeholders
- Zero manual intervention required

## Impact
- ✅ Eliminated manual analysis effort entirely
- ✅ Faster and more reliable release decisions
- ✅ Scales across ~90 modules per cycle
- ✅ Full audit trail maintained in SharePoint
